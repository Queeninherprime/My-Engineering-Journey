- **Completed on:** Today
- **Description:** Completed the first part of the Linux Fundamentals path, covering basic terminal commands, working with files and directories, and searching for files.

## Key Learnings:
- Using `echo`, `pwd`, `ls`, and `cat`.
- Searching for files using `find` and `grep`.
- & executes command but one can be doing other executions while it continues in the background. good for commands that take time
- && it executes command but it would finish execution before doing something else
- > redirects to output and overides the file
-  >> redirects to output and does not override a file
- Find : searches for a file
- grep: searches for a content within a file
